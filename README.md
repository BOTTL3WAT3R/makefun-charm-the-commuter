A one-line weather forecast for Soggport, a harbour city that does not exist: drizzle till noon, one brave hour of sun for the duck race, and lows measured in the mood aboard the 8:05 ferry. The program writes the forecast to /output/entry.txt in the register of a real broadcast forecast, bent just enough to make a bored commuter smile.

## Run it

```sh
python3 main.py
```
